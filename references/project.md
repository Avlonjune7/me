# 项目约定

按当前问题读取相关小节，复用仍有效的项目资料与环境信息。

## 工具与维护

- 更新 me 时同步 [GitHub me 仓库](https://github.com/Avlonjune7/me)、本机全局目录和 CC Switch 技能存储（本机为 `D:/DATA/cc switch/skills/me/`），核对文件一致性；安装与存储路径以实际配置为准。
- 个人 Codex 技能默认安装到用户级全局目录 `~/.agents/skills/`（本机为 `C:/Users/Tars/.agents/skills/`），安装或更新时复用该目录；用户明确要求项目级安装时再使用项目目录。同名技能保持单一安装位置。
- Windows 下额外安装 CLI、开发工具和工具链优先使用 WinGet，支持自选目录时放到 `D:\code\cli\<工具名>`。项目依赖跟随项目，固定路径遵循工具约定，已有安装按用户要求迁移。
- 查文档优先已有专用 CLI 或 Context7。
- Go 本机开发和测试使用宿主目标。部署 Debian 时按服务器架构构建 Linux 产物，纯 Go 可交叉编译，CGO 按项目依赖选择工具链。目标平台变量限于构建进程，部署后验证实际运行。
- 要求整理规范时维护项目代理说明文件（AGENTS.md / CLAUDE.md，依项目使用的工具选择）。项目明确采用 Astryx 时，允许其初始化与升级工具维护自身生成的指引区块。已有 DESIGN.md 继续承载项目设计决定，其他文档通过链接引用。

## 开发与环境

- 复杂任务按依赖拆解并完成相关业务流程与验收。
- 正式功能必须接入真实接口与数据，原型、测试替身及占位明确标识，交付时说明未接通范围。
- 数据库、API 和公共协议变更必须评估调用方与历史数据兼容性，按影响明确迁移、失败恢复及适用的回滚方式。
- 启动、恢复或排障时仅检查相关环境与服务，优先使用项目已有脚本。环境正常且依赖配置未变时直接复用，异常先诊断再恢复或重建。跨会话与隔离环境的可访问性以实际检查为准。

## 项目文档与进度

- 沿用已有等效文档。持续开发的项目以 README.md 为入口，集中运行、环境配置和部署说明，按需维护 docs/PRD.md（需求与验收）、docs/ARCHITECTURE.md（架构设计）和 docs/PROGRESS.md（计划与进度）。已有 PLAN.md 可继续承担进度记录，内容保持单一维护来源。
- 开始任务按需读取相关文档；已建立进度文档的项目在阶段结束或状态变化时更新记录，记录完成情况、验证结果、进行中与待办、阻塞和下一步。需求、架构或运行方式变化时同步对应说明。
- 文档记录稳定配置，运行状态以现场检查为准，凭据使用项目既有管理方式保存。
