# 组件与设计系统

以 Astryx 设计语言作为统一视觉基准，用户当次要求和项目明确约定优先。

- 优先使用官方主题、语义 Token、排版、间距与组件状态。
- 保持简洁、专业、高信息密度，视觉一致性优先通过全局主题和公共组件实现。
- 技术栈与组件实现按项目选择，跨技术栈沿用适用的 Astryx 视觉原则。
- Astryx 的具体用法按需读取其 skill 和项目版本文档，复用有效结论。

React 复杂组件设计与重构按需使用 vercel-composition-patterns，整体设计判断使用 Oil UI Pro，专项审查参照[网页审查](web-review.md)。
