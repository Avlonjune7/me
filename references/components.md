# 组件与设计系统

以 Astryx 统一项目 UI/UX，优化全站视觉一致性，并通过测量改善页面性能。用户当次要求和项目明确约定优先。

- 具体设计、组件、主题及实现规则遵循 Astryx skill 和项目版本文档，按需读取并复用有效结论。
- 技术栈与组件实现按项目选择，跨技术栈沿用适用的 Astryx 设计语言，保留已有业务逻辑与功能。
- 产品界面偏好简洁、专业、高信息密度，在 Astryx 体系内选择适用的主题与布局。
- 默认深化一个方向，用户明确要求比较时再提供多方案。
- 仅在用户明确要求外部案例时查阅，优先复用适用的已有页面或截图。参考用于布局与流程，视觉实现沿用 Astryx 基准及项目明确约定。

React 复杂组件设计与重构按需使用 vercel-composition-patterns。
