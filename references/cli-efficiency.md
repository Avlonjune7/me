# CLI 偏好

## 通用

- 临时 Python 环境按需使用 `uv`/`uvx`。
- 查文档优先已有专用 CLI 或 Context7。
- 大量日志、测试或差异输出可按命令支持情况使用 RTK，保留退出码和关键错误；需要精确诊断或完整审查时读取原始输出。
- Go 本机开发和测试使用宿主目标。部署 Debian 时按服务器架构构建 Linux 产物，纯 Go 可交叉编译，CGO 按项目依赖选择工具链。目标平台变量限于构建进程，部署后验证实际运行。

## 仅 Windows

- 额外安装 CLI、开发工具和工具链优先使用 WinGet，支持自选目录时放到 `D:\code\cli\<工具名>`。项目依赖跟随项目，固定路径遵循工具约定，已有安装按用户要求迁移。
- 命令找不到时，检查当前进程与用户、系统 PATH 的差异及该工具的已知入口，按需补充当前进程 PATH，保留宿主已有入口。常用目录为 `D:\code\cli`，WinGet 便携包也可能在 `D:\code\Portable\User`，仅定位当前工具。
